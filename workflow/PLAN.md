# 金融巨子内容工作流 · 融合实施计划

## 目标

把“每日找题—研究—写稿—花生成片—多平台发布—数据复盘”做成可重复、可追踪、可改进的本地工作流。借鉴 `peanutcut-creator` 的闭环思想，但围绕金融内容增加跨市场事件链、时效衰减、信源审计和中英文舆情。

## 差距矩阵

| 环节 | peanutcut-creator 的启发 | 金融巨子已有 | 本项目融合方案 |
|---|---|---|---|
| 实时发现 | DailyHotApi 热榜，失败时禁止伪造 | Topic Engine V2 评分 | 热榜 + 行情异动 + 财报公告 + 中英文社媒，任一核心源过期时标红 |
| 选题 | 动机、比较优势、反直觉、可执行性 | 时效、异动、跨市场、证据 | 合并成“双层准入”：事件真实性硬门 + 内容传播评分 |
| 人工决策 | 诊断确认、包装确认两个 STOP | 无明确闸门 | Gate 1 选题确认；Gate 2 标题/封面/Hook 确认 |
| 文稿 | 纯口播稿、标点控制、适配花生 | 1000—3000字目标 | 输出“研究底稿”和“花生纯口播稿”两个版本，避免素材说明被朗读 |
| 内容沉淀 | 内容资产库、系列、去重 | 静态面板 | 本地 JSON 资产库，自动存档、检索、系列化、指标回填 |
| 竞品学习 | 抖音公开账号采样设计 | 尚未落地 | 对标账号样本库；按 Hook、节奏、标题、完播、互动拆解 |
| 复盘 | 手动回填指标 | 示例平台表 | 发布后 24h/72h 回填，反向调整选题和包装权重 |
| 成片 | 花生AI纯文稿交接 | 仅跳转官网 | 一键复制纯口播稿 + 制作检查清单 + 成片状态回写 |

## 七项主计划

1. **定位与内容边界**：锁定跨市场科技为主线，A股独立热点为补充；维护禁区、合规表述与受众画像。
2. **实时选题引擎**：接入行情、公告、新闻、热榜和中英文社媒；事件聚类、时间衰减、跨市场传导、历史去重。
3. **爆款表达研究**：持续采样抖音、TikTok、YouTube、B站对标稿，拆 Hook、信息密度、笑点、转折、结尾互动。
4. **深度研究系统**：每题生成事实层、因果层、历史层、大师观点层、反方观点层和可证伪条件。
5. **中视频成稿**：1000—3000字；先研究底稿，再生成纯口播稿和四平台包装变体。
6. **花生AI生产**：纯口播复制、中文标点校验、数字读法校验、9:16/16:9双母版、人工成片验收。
7. **数据闭环**：内容存档、发布日历、24h/72h指标、同类基准比较、规则权重按月调整。

## 里程碑

- **M1 数据可信**：所有候选题显示来源时间、更新时间、跨市场事件链；过期数据不得进入主推。
- **M2 创作闭环**：选题确认后可一路生成研究底稿、标题封面、纯口播并交接花生AI。
- **M3 资产闭环**：每条内容自动存档，历史去重和系列查询可用，发布指标可回填。
- **M4 学习闭环**：对标账号样本与自身表现进入同一分析口径，复盘建议能追溯到具体规则。
