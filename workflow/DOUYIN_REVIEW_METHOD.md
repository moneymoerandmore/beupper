# 抖音作品复盘方法

复盘使用“平台状态 → 分发表现 → 留存表现 → 内容假设”的顺序。只有后台明确出现审核、禁止、删除、私密或违规处罚，才判断平台状态异常；只有播放低而没有状态异常时，统一写“低分发，未证实限流”。

直接证据与推断必须分栏展示。财经风险提示不等于处罚，低播放也不能反推出敏感词命中。2 秒、5 秒和平均观看时长分别用于判断首帧吸引、承诺兑现和内容持续价值；每项结论必须附同账号同期基线。

改进规则须经过多轮同类样本验证。单条作品只形成实验假设，不能直接修改稳定 Skill。跨市场稿件另加事实门禁：指数全名、交易日期、时区、价格区间和信息截点必须一致可追溯；非重叠交易时段的反向涨跌不能被包装成已确认的单因果。
