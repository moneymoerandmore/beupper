# 制作财经双画幅封面

遵循“内容承诺 → 封面策略 → 自动选材 → 图生图 → 双画幅重构 → 检查与保存”的顺序。不要让用户挑选或确认搜索素材，不要在页面展示搜索原图、候选列表、来源卡片或评分。

## 1. 从内容确定承诺

读取当前选题、事件主体、标题、Hook、核心矛盾、研究证据和市场方向。先确定：

- 观众在 0.5 秒内必须认出的对象；
- 想触发的唯一情绪：危险、机会或旧共识被打破；
- 封面故意留下、必须点击才能补齐的信息缺口；
- 正文能够兑现的 4—8 字主锤字。

标题和封面是两个广告位。标题负责搜索对象和完整问题，封面负责更锋利的情绪或判断。禁止原样复述标题、近义改写标题或承诺正文无法兑现的结论。

## 2. 认领封面类型

只选择一种结构：

- 问题、风险和事件解谜题：使用“氛围纪录型、主体主导”。真实主视觉是第一落点，主锤字是第二落点。
- 清晰判断和机制结论题：使用“财经周刊型、大字主导”。主锤字是第一落点，真实主视觉退为次一级证据符号。

禁止让大字、人物、图表和多个物件同时争夺第一落点。第二元素只有在直接构成矛盾时才允许出现。

## 3. 固定系列审美基因

保持“高压财经调查纪录片 × 国际商业周刊封面”的系列语言：

- 石墨黑至深海军蓝的低饱和底色；
- 硬切电影级定向光、真实纸张或金属颗粒、锐利边缘和高明暗反差；
- 紧凑、有压迫感的中文黑体和明确负空间；
- 每期只使用一种信号色：风险用警报红，机会用克制金，疑问用冷白；
- 每期只更换主视觉和主锤字，构图逻辑、材质、字体气质和色彩纪律保持一致。

避免廉价新闻海报、通用 AI 科技蓝、塑料高光、全屏霓虹、金币雨、牛熊雕像、赛博界面、密集 K 线、多图拼贴、账号名、Logo、角标和水印。

## 4. 自动搜索并选择主题素材

必须先搜索素材再做图生图，不以纯文生图冒充完整流程。

1. 从选题提取最能代表主题的实体、动作和场景，用“选题主体 + 视觉锤 + 高清新闻图”形成图片查询。
2. 通过百度 WebSearch 图片模态召回大图和横图；不要扩大每日新闻扫描，也不要把搜索素材写入页面。
3. 对候选执行自动评分：
   - 主题词、实体和动作命中越多，分数越高；
   - 官方、主流财经媒体或当事机构来源加分；
   - 百万像素、适合重新构图的横图和清晰主体加分；
   - Logo、图标、GIF、图库、水印、二维码、广告、缩略图和低清图降权或淘汰。
4. 对高分候选逐一验证 HTTPS 地址、图片类型和可下载性，选择首张通过验证的素材。
5. 没有可信的具名实体图时，继续搜索与主题直接相关的泛化真实场景，例如芯片晶圆、交易大厅、港口、油井或数据中心；不要选择不相关的漂亮图片。
6. 找不到任何合格素材时明确失败并停止，不悄悄切换纯文生图。

自动选择不等于放弃安全：禁止地图；涉及台湾、香港、澳门、新疆或西藏的封面禁止旗帜、国徽和任何人物。不得选择可能造成具名人物、设备型号或事件现场张冠李戴的素材。

## 5. 用参考图完成图生图

把选中的真实素材作为事实主视觉传给图片模型。要求保留主体可识别特征和硬边缘，但重新设计光线、背景、景深、色彩、文字与构图；禁止仅给原图套滤镜，也禁止让主体溶进氛围背景。

提示词必须包含：当期标题但注明不得写入画面、标题与封面分工、核心矛盾、封面类型、唯一视觉锤、固定审美基因、单一信号色、逐字主锤字、禁止元素、目标画幅与安全区。

图中文字只允许一个中文文字块，逐字使用确认后的主锤字；4—8 个汉字优先，最多两行。不得自行增加副标题、英文、股票代码、数字标签或装饰标点。文字与主体之间留出干净负空间。

## 6. 分别重构两个画幅

使用同一参考素材生成两次，禁止先生成一张再裁切另一张。

- 横版固定使用 4:3。四边各留至少 12%，把全部文字、主体完整轮廓和关键识别特征收进中央 76% × 76% 安全框。采用不对称三七构图，视觉锤约占六成，文字负空间约占四成；文字块宽度不超过画面 38%。
- 竖版固定使用 3:4。安全框左边界为 16%、右边界为 78%、顶部为 16%、底部为 74%；右侧 22% 和底部 26% 避让平台按钮、字幕与标题栏。采用“上方钩子—中部唯一重心—下方留空”的纵向视线瀑布，文字块宽度不超过画面 62%、高度不超过 20%。

背景、光影和纹理可以满版出血，但有意义的信息不得越过安全框。禁止文字笔画、头部、手部、产品边缘或主体关键部件贴边、出血、越界或被画布截断。平台从四边轻微裁切后，主视觉和主锤字仍必须完整。

两个画幅必须共享主锤字、参考主体、字体气质、材质与色彩纪律，但允许改变主体位置、景别、光线方向和负空间位置。

## 7. 检查、保存与失败处理

生成后逐张检查：

1. 中文与指定主锤字逐字一致，笔画完整；
2. 缩小到手机信息流后仍能认出话题、情绪和唯一第一落点；
3. 主体身份与参考素材一致，没有凭空增加人物、标志或错误实体；
4. 横版主体未截断，竖版文字未进入顶部、底部或右侧操作区；
5. 标题与封面互补，且正文能够兑现承诺；
6. 不含地图、旗帜、国徽、平台界面、Logo、角标或水印。

只重新生成失败的画幅，保留已经合格的另一张。把横版、竖版、主锤字、提示词、选材查询、素材 URL、来源页面、站点、评分、搜索请求 ID 和生成时间写入同一个项目记录；前台只展示最终两张成品与下载按钮。

## 本项目实现

- 自动选材接口：`app/api/cover-material/route.ts`
- 安全图片代理：`app/api/image-source/route.ts`
- 双画幅工作流与项目保存：`app/creator-workflow.tsx`
- Poe 参考图生成：`scripts/poe_image.py`

修改实现时保持以上四处的数据字段和失败语义一致。
